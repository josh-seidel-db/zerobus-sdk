=== Arrow IPC Binding Strategy ===

To bind Arrow IPC in OCaml, we need:

1. C++ Wrapper (arrow_ipc_bindings.cc):
   - RecordBatchStreamWriter: Write batches → IPC bytes
   - RecordBatchStreamReader: Read IPC bytes → batches
   - Schema serialization: schema → ArrowSchema
   - Column builders: int/string/float columns

2. OCaml FFI Layer (via ctypes):
   - Schema type (opaque ptr to ArrowSchema)
   - RecordBatch type (opaque ptr to Arrow RecordBatch)
   - Writer type (opaque ptr to IPC Writer)
   - Functions:
      * create_int_column(name, values) -> Column
      * create_string_column(name, values) -> Column
      * create_record_batch(schema, columns) -> RecordBatch
      * write_ipc_bytes(batch) -> bytes
      * read_ipc_bytes(bytes) -> RecordBatch

3. Build Integration:
   - Dune rule: compile C++ wrapper with -larrow
   - ctypes stubs: generate OCaml FFI layer
   - Result: Arrow.Ipc module (reader/writer)

=== Current ocaml-arrow Status ===

Project: https://github.com/LaurentMazare/ocaml-arrow
Status: Active but not on opam (as of Aug 2026)

What it provides:
  ✓ Builder API: int64, int32, float64, string columns
  ✓ Writer: write tables to Parquet/Feather files
  ✓ Reader: read Parquet/Feather files
  ✗ IPC codec: NOT exposed in public API

Why the gap:
  - ocaml-arrow focuses on data I/O (Parquet/Feather)
  - IPC codec exists in C++ but wasn't wrapped for OCaml
  - Users typically don't need IPC bytes directly

Path forward:
  1. Extend ocaml-arrow: add Ipc module
  2. Minimal binding: write just the IPC pieces needed
  3. Use Arrow C Data Interface (stable ABI)
